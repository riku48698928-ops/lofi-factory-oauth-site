# LoFi Factory Analytics OAuth site

Minimal public website for the Google OAuth branding configuration of LoFi Factory Analytics.

## Contents

- `index.html` — application home page
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `styles.css` — shared styles

The site intentionally contains no analytics scripts, advertising, cookies, OAuth secrets, tokens, or private operational data.

## Intended GitHub Pages URL

If GitHub Pages is published from the repository root on `main`, the URLs are:

- Home: `https://riku48698928-ops.github.io/lofi-factory-oauth-site/`

Do not place OAuth tokens, refresh tokens, client secrets, analytics data, or other private files in this public repository.
