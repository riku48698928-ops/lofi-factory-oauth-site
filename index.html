LoFi Factory Analytics

A private, non-commercial tool used by its developer to review the performance of videos on their own YouTube channel.

What this application does

LoFi Factory Analytics retrieves read-only YouTube channel, video, and analytics information so the developer can evaluate video performance and improve an automated video-production workflow.

The application is intended for the developer's personal use and is not offered as a public SaaS product or commercial service.

Google / YouTube access

The application requests only these read-only OAuth scopes:

  • https://www.googleapis.com/auth/youtube.readonly
  • https://www.googleapis.com/auth/yt-analytics.readonly

These permissions are used to read YouTube video/channel information and YouTube Analytics metrics. The application does not request permission to upload, edit, or delete YouTube content.

Data handling

Data is processed for the developer's own analytics workflow and is stored only in a private, self-hosted environment controlled by the developer. The application does not sell user data, use it for advertising, or share it with data brokers.

No third-party analytics, advertising scripts, cookies, or tracking pixels are used on this website.
